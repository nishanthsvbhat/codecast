# **App Name**: CodeCast

## Core Features:

- Real-Time Alerts: Receive real-time emergency code alerts, sent by a separate system
- Code Details: View detailed information about each code, including the type of emergency and the specific location within the hospital.
- Acknowledgement: Acknowledge receipt of the alert to indicate awareness and prevent duplicate responses.
- Code History: View a list of active codes and a history of recent codes for situational awareness.
- AI Procedure Summary: Summarize the incident response procedures based on the code type, using an AI tool. This is for quick reference during emergencies.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) to evoke a sense of calm and reliability in critical situations.
- Background color: Very light blue (#E3F2FD) to provide a clean, clinical feel without being sterile.
- Accent color: Slightly darker blue (#42A5F5) to highlight interactive elements and important information, maintaining clarity and focus.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern look that works well for both headlines and body text.
- Use clear, simple icons to represent code types and actions for quick visual recognition.
- Prioritize a clean and intuitive layout with clear hierarchy for rapid information access during emergencies.
- Use subtle animations for alert notifications and acknowledgements to draw attention without causing distraction.
